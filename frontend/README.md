# HireTrack – Job Application Tracking System

HireTrack is a web application that helps users manage and track their job applications, interviews, skills, profile, and resumes in one place.

## 🚀 Live Demo

https://hire-track-tau.vercel.app/

## ✨ Features

* 🔐 User Registration & Login
* 📋 Job Application Tracking
* 📅 Interview Management
* 🛠️ Skills Management
* 👤 Profile Management
* 📄 Resume Upload & PDF View
* 🔒 User-wise Data Separation
* ☁️ Deployed using Vercel

## 🛠️ Technologies Used

* React.js
* Vite
* JavaScript
* Flask
* Supabase
* PostgreSQL
* Axios
* HTML
* CSS

## 📌 Project Purpose

HireTrack helps job seekers organize their placement activities and keep their applications, interviews, skills, profile, and resume information organized in one application.
